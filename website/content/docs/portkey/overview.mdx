## Bring administration into the client

Portkey Admin MCP exposes 194 tools across 22 domains, including prompts, configurations, analytics and governance, to an MCP client. The local stdio server is the starting point.

## Choose the tools you need

Use a Portkey API credential with the appropriate scopes. Select a focused set of tool domains with PORTKEY_TOOL_DOMAINS to keep the catalogue relevant to the task. Domain filtering does not grant API permissions.

## Check API compatibility

This server targets the Portkey-compatible Admin API. Native Prisma AIRS tenant management uses a different API contract. Official AIRS scanning tools are complementary, not an administration replacement.
