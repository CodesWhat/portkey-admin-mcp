## Before you begin

Use the [product installation reference](https://github.com/CodesWhat/portkey-admin-mcp/tree/46556acebb77c9ee224e54836137c64fb5650594) alongside this checklist. Exact commands and settings depend on the release you choose. This guide is grounded in release 0.15.0.

## Your first setup

1. Use Node.js 24 or later and an MCP client that supports local stdio servers.
2. Create a scoped Portkey API credential for the administration tasks you intend to perform.
3. Follow the published release quick start to configure npx portkey-admin-mcp in your client.
4. Select the required tool domains and verify the resulting tool list.
5. Keep credentials in the client configuration or secret storage, never in public site content.

## Make the next step small

Verify the first task end to end before adding more configuration. Keep a record of the release and settings that worked.
