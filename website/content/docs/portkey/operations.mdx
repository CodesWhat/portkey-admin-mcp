## Keep it understandable

- Use the published release documentation when configuring a client. This starter is grounded in 0.15.0.
- Version 0.15.0 uses the MCP v2 SDK and serves protocol revision 2026-07-28 and older clients on the same endpoint.
- HTTP sessions and replay are retired in 0.15.0. The old settings warn and are ignored.
- Review API scopes and enabled tool domains as your use changes.
- Treat the experimental HTTP transport as a separate deployment with its own requirements.
- Do not assume this site provides a hosted MCP endpoint.

## Follow the release

Use the [full product reference](https://github.com/CodesWhat/portkey-admin-mcp/tree/46556acebb77c9ee224e54836137c64fb5650594) for compatibility notes and update instructions, especially when upgrading from 0.14.x. The starter guides here demonstrate a shared documentation surface, not a replacement for the complete product manual.
